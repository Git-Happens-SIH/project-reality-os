What Nirmaan Setu does

Turns daily site reports into live schedule truth. Three core features — what each one does:

  • 1
    Site report

    You write what happened on site (text + photos). Saves on device first so tunnels and low-signal zones still work. Sync pushes when signal returns.

  • 2
    AI match

    AI proposes which plan tasks your report touches. You (or a planner) confirm before anything writes to the schedule. AI proposes — humans decide.

  • 3
    Live dashboard

    Shows every task as Confirmed (safe), Review Needed (human decision), or Possible Risk (delay/conflict). One screen instead of spreadsheet chase.

The loop

Report → AI Match → Approve → Sync. Each step is a task you will do in the product after setup.
